# Knomira art backlog: anatomy and body-zone reference sheets

Status: **Planned** — art/reference backlog, not a commitment to implement the health system before core game playability.

## Objective
Create detailed anatomical and health-zone concept sheets for every approved or explored Knomira race, using the existing compact female Centaur anatomy board as format reference. Preserve each race's already-approved visual baseline.

## Per-sheet deliverables
- [ ] Front, 3/4, profile and rear reference views
- [ ] Facial expressions (neutral, happy, angry, focused, concerned/pained, etc.)
- [ ] Close-ups: head and face; eyes/ears/horns; torso; arms/hands; all limbs; feet/hooves/claws; tail/wings; distinctive scales, fur and plates
- [ ] Visual variation: body builds; skin/fur/scale patterns; hair and tails; horns/ears; armor and equipment fit
- [ ] Simplified colored body-zone overlay and legible silhouette with labels
- [ ] Proposed independently damageable or disableable parts, left/right or fore/hind separated where relevant
- [ ] Consistency check against approved sprite style, proportions, scale and game-facing view

## Future health-panel planning (not yet implementation)
Use shared data-driven body-part definitions with race-specific hierarchies. Distinguish intact, damaged, disabled and destroyed conditions as appropriate; avoid using one humanoid anatomy for every race. Centaurs need four legs and hoof parts; lamias need serpent-tail zones; fauns need hooves; Tinmen and Automaton Gnomes need mechanical components instead of organic wounds.

## Art direction rules
Keep the established ornate, chunky, contrast-rich fantasy pixel art. Do **not** overwrite approved male/female baselines with new interpretations. The expressive face and individual anatomical-part panels are recurring mandatory design elements.

## Definition of done
Each race/body-type has a reference sheet, expression and customization panels, and a simplified health-zone map, reviewed for silhouette readability at target sprite scale.
